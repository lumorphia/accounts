# Lumorphia アカウント プライバシーポリシー

版: 1.0 / 更新日: 2026年10月7日

## 1. 運営者と目的

運営者は t1nyb0x です。ログイン、共通プロフィール、キャラクターの本人確認、利用サービスとの連携、退会・復旧、不正利用の防止と障害対応のために、以下の情報を扱います。広告や追跡目的の分析には利用しません。

この文書は Lumorphia アカウントの情報の扱いを説明します。各サービスの投稿・画像・自己紹介・通報などは、そのサービスのプライバシーポリシーをご確認ください。

## 2. 収集する情報

外部ログインから、プロバイダー名、アカウント ID、表示名、アイコンの URL、提供される場合のメールアドレスと認証トークンを受け取ります。Misskey と Mastodon ではサーバー名も保存します。メールの一致を理由に別のアカウントを結び付けません。

共通アカウントの ID（sub）、handle、表示名、アイコン、連携したログイン方法、作成・更新日時、状態、利用サービスと退会・復旧日時を保存します。登録時の規約・ポリシーの版と同意日時を保存します。15歳以上の確認は同意の条件とし、生年月日は保存しません。

ログインを維持する Cookie とセッションを使います。Cookie は accounts のホストだけに設定し、各サービスと共有しません。セッションには有効期限、接続元 IP、User-Agent を保存します。セッションの有効期間は最長30日で、利用に応じて更新します。

キャラクターを登録すると、The Lodestone の公開情報から ID、名前、ワールド、種族、ジョブ、公開画像などを取得し、本人確認の結果と取得日時を保存します。自己紹介は確認用トークンの照合だけに使い、全文を保存しません。未確認の要求、手動再取得、確認済みキャラクターの週次再取得を行い、過剰なアクセスを避けます。

Prismtone の移行開始時には、旧アカウントの ID・handle・外部ログインの ID の組を受け取り、本人の照合と handle の予約に使います。投稿やメール、認証の秘密は台帳に取り込みません。移行に期限は設けません。

## 3. 利用サービスに渡す情報

登録済みの Lumorphia の利用サービスへ、ログインのための sub と、許可した scope に応じたプロフィール（handle、表示名、アイコン、メール）、アカウントの状態、キャラクターの情報を渡します。引き継ぎ待ちのサービス名をプロフィールに含めます。

外部ログインのプロバイダーと ID の組は、移行に必要な専用 scope（lumorphia:identities）を許可した Prismtone の登録クライアントに限って渡します。外部ログインの認証トークンや Cookie は渡しません。各サービスには退会・復旧・物理削除の状態と時刻を通知します。

## 4. 外部事業者と通信

外部ログインの認証時には、選んだ Discord、Google、X、Misskey または Mastodon のサーバーに接続します。キャラクターの取得では The Lodestone に接続します。それぞれの事業者・サーバーのポリシーが適用されます。

Cloudflare は HTTPS 通信の中継・保護と、R2 によるアイコンの保存・配信・非公開 DB バックアップに使います。中継の際に接続元 IP、HTTP ヘッダーと通信内容を扱います。画像の公開 URL を知る人は画像を取得できるため、アイコンに秘密の画像を使わないでください。

Sentry を有効にする場合、障害の例外・スタック・少量の性能情報を送信します。Cookie、認証ヘッダー、IP、利用者情報、本文、クエリ、SQL、console、入力値を SDK で除きます。エラー時の画面記録は直前最大60秒で、全テキスト・入力を隠し、画像・動画をブロックします。通常の操作だけの画面記録は送信しません。

Cloudflare、Sentry、外部ログインなどの処理は国外で行われる場合があります。運営者は利用する機能、契約上の保護とアクセス範囲を確認して利用します。問い合わせフォームを開き送信した場合は、Google が記入した内容を処理します。

## 5. 保存と削除

プロフィールや連携・キャラクターは利用中保存し、退会後30日経過したら物理削除します。画像は退会直後から削除し、復旧しません。独立したサービス退会の期限と共通アカウントの退会の期限は別に管理します。

削除対象の画像のキーと通知の最小限の記録は処理が完了するまで残し、完了した記録は30日後に削除します。移行前の旧台帳は移行するか旧 Prismtone アカウントを退会するまで残します。台帳の取り込み件数と入力のハッシュは、再取り込みによる復活を防ぐため残します。

非公開の DB バックアップは30日で期限切れとし、順次削除します。保存先の削除処理により反映に時間がかかる場合があります。障害復元にだけ使い、復元時は退会・削除を再適用してからサービスを再開します。HTTP のアクセスログを常時保存せず、アプリの運用ログには認証の秘密や本文を含めません。Sentry の保存期間も最長30日になる設定で運用します。

## 6. 管理とお問い合わせ

管理へのアクセスと権限を制限し、HTTPS、秘密の分離、バックアップ、削除処理と監視を行います。自分のプロフィールと連携の確認・変更は設定画面から行えます。アカウントの削除は退会から行えます。

開示・訂正・利用停止・削除に関する申し出や、この文書への質問は [お問い合わせフォーム](https://forms.gle/cn7FLf8W8gqehL977) へ、Lumorphia アカウントについての連絡と記して送信してください。本人の確認後、法令に従って対応します。

改定時は適用日と内容をサイトで知らせ、収集する情報や提供先などの重要な変更では必要な同意を改めて求めます。
