# Lumorphia デザイン試作 01

端正で落ち着いた、余白・秩序・信頼感を軸にしたブランド案。
灰白色、深い青緑、ゴシック体と控えめな角丸を使い、Prismtone の紙・焼き土・誌面デザインとは別の表情を作る。
シンボルは、開いた輪郭と L を組み合わせた仮案。ロゴ・配色・文言は未確定。

## 確認方法

[index.html](index.html) をブラウザで開く。外部通信やビルドは不要。
上の試作バーでログイン／設定、ライト／ダークを切り替えられる。
画面幅720px以下でスマートフォンの配置になる。

- `?view=settings`: 設定から表示。
- `?theme=dark`: ダークから表示。両方指定可能。
- 設定メニュー、Misskey／Mastodon の展開、フォームの入力と反映を確認可能。
- 表示名とハンドルの変更は画面内だけに反映し、再読み込みで元に戻る。
- 認証・連携・退会などの操作は説明を表示するだけ。実際のAPIやアカウントには接続しない。
- 利用者・連携情報は仮データ。Google・X の記号は配置確認用で、本番のブランド素材ではない。

## デザインの意図

ログインはブランド紹介と操作を左右に配置。スマートフォンは紹介を短くして操作を優先する。
ブランドコピーは紹介部分に限定し、フォームと設定の見出しは機能を明確に伝える。
設定では左の案内と右の編集領域を揃え、操作対象と影響範囲を近くに表示する。
ダークは青みのある墨色と淡い青緑を使い、ライトと同じ構造を保つ。

本番アプリは変更していない。既存の登録同意・復旧・移行フローをすべて再現する試作ではなく、ログインと設定の基本構成を比較するためのもの。
