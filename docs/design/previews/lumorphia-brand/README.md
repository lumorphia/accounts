# Lumorphia アカウント デザイン試作 02

Lumorphia の website で採用された世界観を、アカウント画面に展開した案。
既存の Lumorphia ロゴ、青紫寄りの白、落ち着いた藍色、余白と揃った配置を使う。
大きなロゴと光はログインとトップに使い、登録・設定では情報と操作を優先する。

## 開く

[index.html](index.html) をブラウザで開く。ビルド・外部通信は不要。
上の試作バーでログイン／初回登録／ログイン後／設定、ライト／ダークを切り替えられる。

- `?view=login` / `?view=welcome` / `?view=home` / `?view=settings` で最初の画面を指定。
- `?theme=dark` でダーク表示。画面指定と併用可能。
- 幅720px以下ではスマートフォンの配置。

## 画面

- ログイン：Discord・Google と Lumorphia トップへの戻り先を案内。Misskey／Mastodon は展開してサーバーを入力。
- 初回登録：表示名・ユーザーIDと15歳以上の確認、利用規約・プライバシーポリシーへの同意。2つのチェックが入ってから設定完了へ進める。
- ログイン後：通常の Lumorphia トップを表示。ヘッダーのアカウントメニューからアカウント管理へ進む。専用のダッシュボードは設けない。
- 設定：プロフィール・ログイン方法・キャラクター・アカウント管理を切り替える。PCは左の案内と右の編集領域、スマートフォンは横の案内と縦の編集領域。

## 試作の範囲

このHTMLは実装アプリとは独立した試作で、利用者名・連携状態は仮データ。
採用後の実装は [実画面の確認画像](../../implemented/README.md) を参照。
ログインボタンは認証せず、ログイン後のトップ表示へ切り替える。連携・退会・画像変更・外部移動も実行しない。
登録とプロフィール保存は試作内だけに反映し、再読み込みで元に戻る。
規約リンクは試作では案内表示のみ。実際の同意や登録を記録しない。

この案では Lumorphia からのログイン後は Lumorphia トップへ戻る。
本番の認証・OIDCコールバックや戻り先の処理は変更していない。
既存の移行・復旧・規約本文の画面や、すべてのAPIエラー状態を再現するものではない。

## 素材

`assets/` の Lumorphia ロゴと Prismtone の文字のみ版 SVG は、website の採用素材をそのままコピーしている。
提供されたロゴを加工せず、Prismtone はライト／ダークの配色を切り替える。
Prismtone ロゴ書体のライセンスを `assets/Cormorant-OFL.txt` に同梱。
Google の文字記号は配置確認用で、本番のブランド素材ではない。
大きな Lumorphia ロゴの背後にCSSで光を加え、トップのヒーローと同じ上下左右のフェードで背景に溶かす。
トップの Prismtone 写真も website の採用素材をコピーし、表示時のフッターに `© SQUARE ENIX` を記載している。

## X ログイン

X は当面利用しないため、この試作のログインと新規連携には出さない。
本番実装の X 対応と `AUTH_X_ID` / `AUTH_X_SECRET` の設定項目は残す。
両方を未設定にしておけばプロバイダーが有効にならず、ログイン・連携のボタンも表示されない。
既存の連携データと移行処理は変更しない。過去の試作は当時の状態のまま残す。

## 年齢条件の説明

FFXIV の利用規約「未成年の方へ」に15歳以上と明記されていることを確認（2026-10-10）。
初回登録では、この条件に合わせて Lumorphia も15歳以上を対象としていることを説明し、[公式規約](https://support.jp.square-enix.com/rule.php?id=5381&tag=users)にリンクする。
画面の用語は「ユーザーID」に統一する。
